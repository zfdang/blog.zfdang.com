语音搭子 (Voice Input Buddy)：让吃灰的蓝牙遥控器成为 Mac 语音输入神器

Zhengfa Dang
2026-10-16
MacOS, 开源软件, 效率工具, 语音输入

在日常文字输入、写文章、回邮件或者记录灵感时，语音输入的高效往往是键盘无法比拟的。

如今像微信输入法、豆包输入法以及 Typeless 这类现代化 AI 语音工具，语音识别的准确率和智能润色效果已经极其惊艳。但在 Mac 上使用语音输入，往往会遇到一个尴尬的操作体验问题：

  • 姿态受限：手必须一直悬在键盘上按住快捷键（比如连按两次 Fn 或长按 Option）；
  • 拾音距离尴尬：想要靠在椅背上放松思考，Mac 自带的麦克风距离太远，环境稍有噪音识别率就大打折扣；
  • 不够自然随手：缺乏那种“拿起就说、说完就走”的轻快感。

其实很多人家里都有闲置吃灰的电视盒子遥控器（例如小米蓝牙语音遥控器、Google Chromecast G9N9N 遥控器等）。这些遥控器做工精巧、握持手感舒适，自带高品质近场降噪麦克风，还有手感极好的实体物理按键。

能不能把这只遥控器连到 Mac 上，让它变成一只专属的无线语音输入手柄？

这就是开源项目 Voice Input Buddy（语音搭子） 诞生的原因。

核心原理：不造重复的轮子，只做最纯粹的桥梁

市面上有一些语音输入软件喜欢内嵌体积巨大的离线语音模型，结果不仅 App 体积动辄几个 G，Mac 风扇呼呼转，识别速度和准确度还远比不上大家平时习惯用的输入法。

Voice Input Buddy 选择了极其克制与优雅的设计思路：专注于硬件与输入工具之间的系统级桥梁。

  1. 音频直通：遥控器通过蓝牙发送私有音频流，语音搭子将其实时解码并输入到内置的 Voice Input Buddy Mic 虚拟麦克风驱动中；
  2. 快捷键联动：按下遥控器语音键时，语音搭子同时向系统发送输入法的唤醒按键；
  3. 输入法识别：你常用的输入法（或听写工具）从该虚拟麦克风拾取高保真声音，完成高精度文字识别并上屏；
  4. 隐私零顾虑：纯本地管道桥接，不保存任何录音，不上传任何文字历史或使用统计，零远程网络请求。

支持的硬件设备

语音搭子目前重点适配了多款主流常见的蓝牙遥控器：

  • 小米蓝牙语音遥控器：如常见的小米电视遥控器 2 代 / 2 Pro（RC001 / RC003 等）；
  • **Google Chromecast Voice Remote (G9N9N)**；
  • **Google TV Streamer Voice Remote (GY3LE)**；
  • Apple Siri Remote；
  • 手机伴侣模式：如果你身边暂时没有实体遥控器，还可以使用手机扫码，把手机浏览器直接变成语音输入遥控手柄。

在主界面的“设备连接”面板中，可以同时管理多台已配对的遥控器，实时查看蓝牙连接状态、剩余电量与充电状态，甚至可以为每只遥控器单独微调麦克风输入增益（0 dB 至 20 dB）：

核心功能与使用体验

1. 7 步新手引导向导，开箱即用

为了让初次配置毫无门槛，App 内置了清晰的交互式新手向导，一步一步带领你完成初始化：

  1. 系统权限检查：一键授权蓝牙、输入监控和辅助功能；
  2. 控制设备类型：选择实体遥控器或手机伴侣；
  3. 蓝牙连接遥控器：图文图解按键配对组合（如长按主页+菜单键）；
  4. 实体按键测试：按下遥控器任意按键，屏幕即时亮起反馈；
  5. 声卡驱动检查：确认虚拟麦克风驱动状态完好；
  6. 输入工具配置：针对微信输入法、豆包等提供截屏式的快捷键指引；
  7. 试说录音与微调：按住语音键说出第一句话，实时核对上屏效果与音量。

2. 全按键可视化映射

除了中央核心的麦克风语音键之外，遥控器上的其他物理按键也都物尽其用：

  • 支持为电源键、确定键、五向导航键、返回键、主页键、菜单键与 TV 键独立分配动作；
  • 每颗按键均支持单击、双击、长按三种独立触发模式；
  • 不仅可以绑定常规快捷键（如 Spotlight 搜索、复制粘贴、截图），还可以绑定应用切换、系统多媒体控制等。

3. 五向键“常用语面板”：高频回复一键即发

在按键映射中，还内置了一个非常实用的“常用语”功能：

你可以把遥控器的圆盘方向键（上、下、左、右）和 OK 键分别绑定常用的短语、邮箱地址、客服常用回复或终端命令。在任何输入框中按下对应按键，文字即可瞬间上屏，无需反复打字或剪贴板查找。

4. 深度适配主流输入工具

无论你习惯用哪款输入法，语音搭子都提供了顺手的集成入口：

  • 微信输入法：支持长按空格/语音键模式，识别速度极快，标点符号智能推断；
  • 豆包输入法：深度集成字节豆包大模型，语境理解与中英混说极佳；
  • Typeless：新一代 AI 语音听写神器，支持语气词过滤与文本智能润色；
  • Vokie / VoiceCursor 等现代语音辅助工具。

下载与安装

  • 项目官网：https://voice.zfdang.com/
  • GitHub 仓库：https://github.com/zfdang/voice-input-buddy
  • 下载最新安装包：在 GitHub Releases 中下载对应架构的 .pkg 安装包即可。

系统要求：macOS 14.0 (Sonoma) 及以上版本，原生支持 Apple Silicon (M 系列芯片) 与 Intel 架构。

安装包内已包含 App 本身以及配套的低延迟虚拟麦克风驱动，安装过程无需单独折腾额外的音频虚拟跳线软件（如 BlackHole 等）。

结语

硬件复用不仅环保，而且电视遥控器那种符合人体工学的握持感和按压反馈，是用键盘快捷键输入完全无法比拟的。

平时写东西或者看文献时，背靠椅子，单手握着遥控器，按住说话、松开上屏，整个打字与记录灵感的过程变得轻松又自然。如果你家里也有闲置的蓝牙电视遥控器，强烈推荐找出来试试看！
